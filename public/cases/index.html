03 / PLANNING EXAMPLES

空間に置く、
その前に。

ローカル資料に含まれる空間イメージと製品画像を、用途別の配置検討資料として整理しました。以下は導入実績ではありません。

EXAMPLE 01

個人作業と会話を、同じフロアに。

用途

一人用ブースとミーティング向けブースを同じオフィス内に配置する場合の検討イメージです。動線、扉の開閉、周辺家具との距離は現地条件に合わせて確認が必要です。

掲載区分：配置検討例 / 非実際納入事例。実際の納入事例ではありません。

EXAMPLE 02

開放空間の中に、集中の選択肢を。

用途

共有エリアに複数のブースを置き、個人作業と少人数の会話を分ける場合の検討イメージです。設置数量や機種は利用人数と運用方法から選定します。

掲載区分：配置検討例 / 非実際納入事例。実際の納入事例ではありません。

PROJECT MATERIALS NEEDED

実績ページ化に必要な資料。

正式な導入事例として掲載するには、案件種別、設置地域、導入規模、採用SKU、提供範囲、完成写真3点以上、掲載許諾が必要です。
